    Frappe (TAP LMS) — server install

    Production / staging install of a TAP LMS Frappe site on a Linux server. Internal doc — not published. Sanitized consolidation of the team's Notion install notes.

    🔒 No secrets in this file, by design. DB passwords, the site encryption_key, SSH keys, API tokens → pull from GCP Secret Manager (or your vault) at run time. Never paste real secrets into this repo (it's shared). Placeholders below: <SITE> (e.g. tap_lms.prod), <your-domain>, <DB_PASSWORD>, <LINUX_USER>.

    Stack

    Ubuntu 22.04 (prod) or 24.04 · Frappe v15 · PostgreSQL (not MariaDB) · Node 18 · nginx + supervisor + redis. Prod runs on GCP with python3.12.

    TAP-LMS is PostgreSQL. Ignore any MariaDB steps from the older Notion pages — those were for other, non-TAP projects.

    1. System packages

    sudo apt-get update -y && sudo apt-get upgrade -y
sudo apt-get install -y software-properties-common curl git

# Python 3.12 — native on 24.04; on 22.04 add deadsnakes:
sudo add-apt-repository -y ppa:deadsnakes/ppa && sudo apt-get update -y
sudo apt-get install -y python3.12 python3.12-dev python3.12-venv python3-pip python3-setuptools

# PostgreSQL, Redis, process mgmt, PDF, web server
sudo apt-get install -y postgresql postgresql-contrib postgresql-client
sudo apt-get install -y redis-server supervisor nginx fail2ban
sudo apt-get install -y xvfb libfontconfig wkhtmltopdf
sudo systemctl enable --now postgresql redis-server

    2. Node 18 + yarn

    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
source ~/.profile
nvm install 18 && nvm use 18
sudo npm install -g yarn

    3. PostgreSQL

    Set a password for the postgres role (take the value from Secret Manager):

    sudo -i -u postgres psql -c "\password postgres"   # paste <DB_PASSWORD> when prompted

    Frappe's bench new-site --db-type postgres will create the app DB/role using this.

    4. Bench

    pip3 install frappe-bench
bench init frappe-bench --frappe-branch version-15 --python python3.12
cd frappe-bench

    5. Create the site (PostgreSQL)

    bench new-site <SITE> --db-type postgres --db-host localhost
bench --site <SITE> enable-scheduler
bench use <SITE>

    6. Get the TAP apps

    Pin to the canonical branch (pal-v2 — feature/RAG is legacy):

    bench get-app --branch pal-v2 https://github.com/DalgoT4D/frappe_tap.git
bench get-app https://github.com/Midocean-Technologies/business_theme_v14.git

bench --site <SITE> install-app tap_lms
bench --site <SITE> install-app business_theme_v14
bench --site <SITE> migrate

    7. Production setup

    # nginx
bench setup nginx
sudo ln -s `pwd`/config/nginx.conf /etc/nginx/conf.d/frappe-bench.conf
# edit server_name -> <your-domain> (or the public IP)
sudo nginx -t && sudo systemctl restart nginx

# supervisor + socketio + redis
bench setup supervisor
sudo ln -s `pwd`/config/supervisor.conf /etc/supervisor/conf.d/frappe-bench.conf
bench setup socketio
bench setup redis
sudo supervisorctl reload

# production wiring (workers, scheduler, perms)
sudo bench setup production <LINUX_USER>
sudo chmod -R o+rx /home/<LINUX_USER>
bench restart

    8. TLS

    sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot -d <your-domain> --nginx

    9. Verify

    bench --site <SITE> list-apps        # tap_lms, business_theme_v14, frappe
cd apps/tap_lms && git status        # on pal-v2

    After install — TAP configuration

    Getting the bench + site + apps up is only half the job. First-run TAP config (Glific contact fields via dev_tools.bootstrap_sp_contact_fields(), VoiceAgentSettings, ParentCallConfig, curriculum, cohort) is in deployment-runbook.md Phase 6 — follow it before declaring the site live.
