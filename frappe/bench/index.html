    Frappe bench skill

    Launch context: project root. For bench commands, cd ~/frappe-bench first.

    bench is a CLI wrapper around Frappe that orchestrates: per-site DBs, app installation, migrations, asset builds, workers, scheduler, and backups. The cardinal rule is: most "did my change take effect?" mysteries are solved by bench restart and bench --site <site> clear-cache.

    Layout

    A bench is a directory with this structure:

    frappe-bench/
├── apps/
│   ├── frappe/
│   ├── erpnext/
│   └── tap_lms/        ← your custom app
├── sites/
│   ├── apps.txt
│   ├── common_site_config.json
│   └── <sitename>/
│       ├── site_config.json
│       ├── public/
│       └── private/
├── env/                # Python virtualenv
└── config/             # nginx, supervisor, redis configs

    apps/<app> is a normal git repo — work there exactly like any other Python package.

    First-time setup (Postgres)

    # Install bench CLI
pip install frappe-bench

# Init a bench tracking v15
bench init --frappe-branch version-15 frappe-bench

cd frappe-bench

# Tell bench to use Postgres for new sites
bench set-config -g db_type postgres
bench set-config -g db_host 127.0.0.1
bench set-config -g db_port 5432

# Create a new site backed by Postgres
bench new-site tap.local \
    --db-type postgres \
    --db-host 127.0.0.1 \
    --db-root-username postgres \
    --admin-password admin

# Get your custom app
bench get-app tap_lms <git-url-or-local-path>
bench --site tap.local install-app tap_lms

# Start the dev server (web + scheduler + workers + watcher)
bench start

    Day-to-day commands

    Every site-scoped command takes --site <name> (or set a default with bench use <site>).

    Migration & schema

    bench --site tap.local migrate          # Apply DocType JSON changes + run patches
bench --site tap.local reload-doctype "Course Enrollment"  # Re-read one DocType from disk
bench --site tap.local clear-cache      # Wipe metadata + Redis caches
bench --site tap.local clear-website-cache

    migrate is the one you'll run constantly. If a migration fails midway, fix the cause and re-run; patches that already ran are skipped (tracked in tabPatch Log).

    App lifecycle

    bench new-app tap_lms                   # Scaffold a new app
bench --site tap.local install-app tap_lms
bench --site tap.local uninstall-app tap_lms
bench --site tap.local list-apps

    Build & assets

    bench build                  # Build all apps' JS/CSS bundles
bench build --app tap_lms    # Just yours
bench watch                  # Live rebuild on change (dev)

    After editing .bundle.js files or anything in public/, run bench build (or have bench start running, which calls watch).

    Restart

    bench restart                # Reload web workers + queue workers + scheduler
bench restart --supervisor   # Production: restart via supervisorctl

    Restart whenever you change hooks.py, install/uninstall an app, or change Python code that's imported at startup. Lifecycle methods inside DocType controllers don't need a restart (they're imported per request).

    Backups

    bench --site tap.local backup                    # SQL only
bench --site tap.local backup --with-files       # SQL + private/public files
bench --site tap.local backup --compress
ls sites/tap.local/private/backups/              # ← they land here

    Restore:

    bench --site tap.local restore <path/to/backup.sql.gz> \
    --with-public-files <path/to/files.tar> \
    --with-private-files <path/to/private.tar>

    For Postgres, the backups are produced by pg_dump; restore uses pg_restore under the hood.

    Console & ad-hoc execution

    bench --site tap.local console
# Drops into IPython with `frappe` already imported and the site context loaded.

bench --site tap.local execute tap_lms.api.enroll --kwargs '{"student": "STU-001", "course": "CS101"}'
# Run any function with the site context — great for one-off scripts.

bench --site tap.local run-tests --app tap_lms

    Workers & scheduler

    bench worker --queue default,short,long   # one worker per queue family
bench schedule                            # the scheduler daemon

    In production these are managed by supervisor (config/supervisor.conf is generated by bench setup supervisor). In dev, bench start runs them all under honcho.

    Switching Frappe versions / branches

    cd apps/frappe
git checkout version-15    # or whichever
cd ../..
bench setup requirements    # reinstall Python deps
bench --site tap.local migrate
bench build
bench restart

    Same pattern for any app: checkout the branch in apps/<app>, run setup requirements, migrate, build, restart.

    Detecting the current version

    bench version                              # versions of all apps
bench --site tap.local version             # same, plus site DB schema version
cat apps/frappe/frappe/__init__.py | grep "^__version__"

    Common operational issues

    "My JS changes don't show up" — Browser cache, then bench build, then bench --site <site> clear-cache, in that order.

    "My new doc_event doesn't fire" — hooks.py change without bench restart. Restart and retry.

    "Scheduler isn't running my hourly job" — In dev, bench start must be running. In prod, supervisor must be up and enabled_scheduler_events in site config must include the relevant frequency. Check tabScheduled Job Log for evidence the scheduler is alive.

    "I added a new entry to scheduler_events.cron in hooks.py, ran bench restart, and it never fires" — Restart reloads code but does NOT re-sync scheduler_events into the DB. Frappe stores scheduler entries in the tabScheduled Job Type table; that table is populated from hooks.py only by bench --site <site> migrate. Rule: after editing scheduler_events, run bench --site <site> migrate AND bench restart. Editing doc_events only requires restart. Verify by querying tabScheduled Job Type WHERE method LIKE '<your_module>%' after migrate.

    "My RQ background job runs but no data appears (silent success)" — The job's outer except swallows exceptions without re-raising. RQ marks the job "finished" because no exception propagated, but the work the job was supposed to do never landed. Rule: every RQ job's outer except branch must end with raise (after any frappe.db.rollback() + frappe.log_error). Check FailedJobRegistry to see if your jobs are actually failing: in bench console, from tap_lms.summer_program.sp_console import queue_failures_for; queue_failures_for("<func_name>").

    "Site won't load: connection refused" — Postgres or Redis isn't running. pg_isready -h 127.0.0.1 -p 5432, redis-cli ping.

    "bench migrate fails with permission denied" — The Postgres user lacks CREATE on the DB. Either grant it (GRANT ALL ON DATABASE <db> TO <user>) or run migrate as a privileged user once.

    "Out of memory during build" — bench build runs node/esbuild and can be hungry. On small servers, NODE_OPTIONS=--max-old-space-size=2048 bench build.

    Production knobs

    bench setup production <user> writes nginx + supervisor configs. After:

    sudo supervisorctl reread && sudo supervisorctl update
sudo nginx -s reload

    bench setup nginx regenerates nginx config (run after adding a site or changing SSL). bench setup supervisor regenerates worker configs (run after changing worker counts in common_site_config.json).

    For Postgres specifically, ensure pg_hba.conf allows the bench user from 127.0.0.1 (host <db> <user> 127.0.0.1/32 md5) and max_connections is high enough — calculate (workers × queues) + gunicorn workers + a buffer and add 20%.

    A short cheat sheet

    bench --site tap.local migrate                 # after a DocType JSON or hooks.scheduler_events change
bench restart                                   # after a hooks.py doc_events / Python import-time change
bench --site tap.local clear-cache              # after metadata weirdness
bench build                                     # after JS / CSS / .bundle changes
bench --site tap.local console                  # poke around live data
bench --site tap.local backup --with-files      # before doing anything risky
bench --site tap.local run-tests --app tap_lms  # before pushing

    If you can't remember which one you need, run all five (in order) — they're idempotent and the whole sequence takes well under a minute on a small site.

    Console — use sp_console instead of pasted snippets

    Bench console is IPython under the hood. Two failure modes hit repeatedly when pasting raw diagnostic snippets:

    1. Generator/closure-scope NameError. A def or genexp inside a multiline cell sometimes fails to capture imports declared in the same cell. Workarounds (split into separate cells; inline everything) are fragile.
    2. Placeholder-syntax SyntaxError. Snippets with placeholders like [...names from above...] parse as invalid Python before any comment is read.

    The fix is to call functions, not paste cells. Save the helper code below to a personal file on the bench server (the team convention is ~/sp_console.py), then load it into your console session.

    These helpers are developer tooling only — NOT part of the shipped tap_lms app. They live in this skill file as a copy-paste reference (one canonical version everyone shares) rather than in app/tap_lms/ because they don't belong in production code paths.

    Setup (one-time per bench server)

    # On the bench server, save the helper code below to ~/sp_console.py
# (the file lives outside the bench checkout, so it's not in git and
#  not shipped with the app).
vim ~/sp_console.py

    Usage in bench console

    # Load the helpers once per console session
exec(open("/home/<your-user>/sp_console.py").read())

# Now the functions are available
pe_health("ST00051246")                           # PE / Glific / API 3-way comparison
pe_events("ST00051246", limit=20)                 # last N ProgramEventLog entries
cohort_drift("palv2-test-BT52231")                # read-only cohort sweep
cohort_status_breakdown("palv2-test-BT52231")     # status × resolved_flow_state counts
collection_diff("palv2-test-BT52231", main_group_id="20529")  # MAIN_ELIGIBLE_STATES-aware
enqueue_health()                                  # Redis + queues + workers + smoke test + recents
queue_failures_for("job_log_content_completion")  # see if a function has historical failures
scheduled_crons()                                 # verify bench migrate registered new entries
glific_fields("306187")                           # pretty-print SP-managed contact fields

    When to update this skill file

    When you write a new diagnostic during a session, save it BOTH to your local ~/sp_console.py AND propose appending the function to this skill file via PR. The skill file is the canonical version; local files are working copies that should match.

    Conventions: - Top-level def (no closures over imports declared in console). - First line is frappe.db.rollback() (clears any poisoned txn from a prior cell). - Accept explicit string args, not in-cell mutable references. - Return a dict; gate the print output on verbose=True. - Read-only by default; prefix mutating functions with repair_.

# ── PE / student state inspection ───────────────────────────────

def pe_health(student_id: str, verbose: bool = True) -> Dict[str, Any]:
    """3-way comparison: PE row / Glific contact / get_student_state API."""
    frappe.db.rollback()

    pe_row = frappe.db.sql(
        """
        SELECT name, glific_id, program_status, current_week, current_path,
               current_tier, resolved_flow_state, journey_label,
               total_points, current_streak, special_gems,
               total_activity_points, weekly_activity_points,
               total_quiz_points, weekly_quiz_points, bonus_quiz_points,
               total_submission_points, weekly_submission_points,
               weekly_submission_done, weekly_video_done,
               current_escalation_step, current_escalation_type,
               in_grace_window, grace_window_end_at,
               next_action_at, next_action_type
          FROM "tabProgramEnrollment"
         WHERE student = %s AND program_status IN ('active', 'paused')
         ORDER BY modified DESC LIMIT 1
        """,
        (student_id,), as_dict=True,
    )
    if not pe_row:
        if verbose:
            print(f"no active/paused PE for {student_id}")
        return {"pe": None, "glific": None, "api": None, "drift": []}
    pe = pe_row[0]

    glific = _fetch_glific_contact(pe["glific_id"]) if pe.get("glific_id") else {}
    api = _call_get_student_state(student_id)

    drift = []
    pairs = [
        ("resolved_flow_state", "resolved_flow_state"),
        ("current_week", "current_week"),
        ("current_streak", "current_streak"),
        ("special_gems", "special_gems"),
        ("total_points", "total_points"),
        ("total_quiz_points", "total_quiz_points"),
        ("bonus_quiz_points", "bonus_quiz_points"),
        ("weekly_quiz_points", "weekly_quiz_points"),
        ("weekly_activity_points", "weekly_activity_points"),
        ("weekly_submission_points", "weekly_submission_points"),
        ("escalation_type", "current_escalation_type"),
    ]
    for glific_key, pe_key in pairs:
        pe_val = pe.get(pe_key)
        glific_val = glific.get(glific_key)
        if glific_val is None:
            continue
        if str(pe_val) != str(glific_val):
            drift.append({"key": glific_key, "pe": pe_val, "glific": glific_val})

    if verbose:
        print(f"\nPE.{pe['name']}  student={student_id}  status={pe['program_status']}")
        print(f"  state={pe['resolved_flow_state']}  week={pe['current_week']}  "
              f"tier={pe['current_tier']}  path={pe['current_path']}")
        print(f"  total={pe['total_points']}  streak={pe['current_streak']}  "
              f"gems={pe['special_gems']}  bonus={pe['bonus_quiz_points']}")
        print(f"  weekly: video={pe['weekly_video_done']} "
              f"submission={pe['weekly_submission_done']} "
              f"q={pe['weekly_quiz_points']} a={pe['weekly_activity_points']} "
              f"s={pe['weekly_submission_points']}")
        if pe['current_escalation_step']:
            print(f"  escalation step={pe['current_escalation_step']} "
                  f"type={pe['current_escalation_type']}")
        if pe['next_action_type']:
            print(f"  next: {pe['next_action_type']} at {pe['next_action_at']}")
        print(f"\ndrift items ({len(drift)}):")
        for d in drift:
            print(f"  {d['key']:30s} PE={d['pe']!r:15s} Glific={d['glific']!r}")

    return {"pe": pe, "glific": glific, "api": api, "drift": drift}


def pe_events(student_id_or_pe: str, limit: int = 20,
              verbose: bool = True) -> List[Dict[str, Any]]:
    """Last N ProgramEventLog rows. FK column is `enrollment` (L-052)."""
    frappe.db.rollback()

    if student_id_or_pe.startswith("ST"):
        pe_name = frappe.db.get_value(
            "ProgramEnrollment",
            {"student": student_id_or_pe,
             "program_status": ["in", ["active", "paused"]]},
            "name", order_by="modified desc",
        )
    else:
        pe_name = student_id_or_pe

    if not pe_name:
        if verbose:
            print(f"no PE found for {student_id_or_pe}")
        return []

    rows = frappe.db.sql(
        """
        SELECT creation, event_type, trigger_source,
               old_value, new_value,
               LEFT(details::text, 200) AS details
          FROM "tabProgramEventLog"
         WHERE enrollment = %s
         ORDER BY creation DESC LIMIT %s
        """,
        (pe_name, limit), as_dict=True,
    )
    if verbose:
        print(f"\nLast {len(rows)} events for PE {pe_name}:")
        for r in rows:
            print(f"  {r['creation']}  {r['event_type']:30s}  "
                  f"src={r['trigger_source']!r:14s}  "
                  f"{r['old_value']!r} → {r['new_value']!r}")
    return rows


# ── Cohort-wide diagnostics ─────────────────────────────────────

def cohort_drift(batch_name: str, verbose: bool = True) -> Dict[str, Any]:
    """Read-only cohort sweep via dev_tools.reconcile_batch_to_glific(dry_run=True)."""
    frappe.db.rollback()
    from tap_lms.summer_program import dev_tools
    return dev_tools.reconcile_batch_to_glific(
        batch_name, dry_run=True, verbose=verbose,
    )


def cohort_status_breakdown(batch_name: str,
                            verbose: bool = True) -> List[Dict[str, Any]]:
    """PE counts grouped by (program_status, resolved_flow_state)."""
    frappe.db.rollback()
    rows = frappe.db.sql(
        """
        SELECT program_status, resolved_flow_state, COUNT(*) AS n
          FROM "tabProgramEnrollment"
         WHERE batch = %s
         GROUP BY program_status, resolved_flow_state
         ORDER BY n DESC
        """,
        (batch_name,), as_dict=True,
    )
    if verbose:
        print(f"\nPE breakdown for {batch_name}:")
        for r in rows:
            print(f"  {r['program_status']:12s} "
                  f"{r['resolved_flow_state'] or '-':30s}  {r['n']}")
    return rows


def collection_diff(batch_name: str, main_group_id: str,
                    verbose: bool = True) -> Dict[str, Any]:
    """Filter PEs by MAIN_ELIGIBLE_STATES (CR-005) before diffing against
    the Glific group. grace_waiting / escalation / paused are excluded
    by design, not 'missing' (L-055)."""
    frappe.db.rollback()
    from tap_lms.summer_program.collection_membership import MAIN_ELIGIBLE_STATES
    from tap_lms.glific_integration import (
        get_glific_settings, get_glific_auth_headers,
    )

    pes = frappe.db.sql(
        """
        SELECT pe.name, pe.student, pe.glific_id,
               pe.program_status, pe.resolved_flow_state
          FROM "tabProgramEnrollment" pe
         WHERE pe.batch = %s
           AND pe.program_status IN ('active', 'paused')
        """,
        (batch_name,), as_dict=True,
    )
    eligible_by_gid = {}
    for p in pes:
        if p["glific_id"] and p["resolved_flow_state"] in MAIN_ELIGIBLE_STATES:
            eligible_by_gid[str(p["glific_id"])] = p
    eligible_gids = set(eligible_by_gid.keys())

    settings = get_glific_settings()
    r = requests.post(
        f"{settings.api_url}/api",
        json={
            "query": "query g($id: ID!){group(id:$id){group{id contacts{id phone}}}}",
            "variables": {"id": str(main_group_id)},
        },
        headers=get_glific_auth_headers(), timeout=30,
    ).json()
    contacts = (((r.get("data") or {}).get("group") or {}).get("group") or {}).get("contacts") or []
    collection_gids = {str(c.get("id")) for c in contacts}

    missing = eligible_gids - collection_gids
    extra = collection_gids - eligible_gids

    if verbose:
        print(f"\nEligible for main collection: {len(eligible_gids)}")
        print(f"Collection members on Glific:  {len(collection_gids)}")
        print(f"\nMissing from collection ({len(missing)}):")
        for gid in missing:
            p = eligible_by_gid[gid]
            print(f"  {p['name']}  student={p['student']}  gid={gid}  "
                  f"state={p['resolved_flow_state']}")
        print(f"\nExtra in collection ({len(extra)}):")
        for gid in extra:
            print(f"  gid={gid}")

    return {
        "eligible_gids": list(eligible_gids),
        "collection_gids": list(collection_gids),
        "missing": list(missing),
        "extra": list(extra),
    }


# ── Background-job + queue health ───────────────────────────────

def enqueue_health(verbose: bool = True) -> Dict[str, Any]:
    """6-step roll-up: Redis ping + queues + workers + recent jobs + smoke test."""
    frappe.db.rollback()
    out: Dict[str, Any] = {}

    try:
        from frappe.utils.background_jobs import get_redis_conn
        out["redis_ping"] = get_redis_conn().ping()
    except Exception as e:
        out["redis_ping"] = f"ERROR: {e}"

    try:
        from frappe.utils.background_jobs import get_queue
        queues_info = {}
        for name in ("short", "default", "long"):
            q = get_queue(name)
            queues_info[name] = {
                "actual_name": q.name,
                "depth": len(q),
                "failed": q.failed_job_registry.count,
                "scheduled": q.scheduled_job_registry.count,
                "started": q.started_job_registry.count,
            }
        out["queues"] = queues_info
    except Exception as e:
        out["queues"] = f"ERROR: {e}"

    try:
        from rq import Worker
        from frappe.utils.background_jobs import get_redis_conn
        workers = Worker.all(connection=get_redis_conn())
        out["workers"] = [
            {"name": w.name, "state": w.get_state(),
             "queues": [qq.name for qq in w.queues],
             "birth": str(w.birth_date)}
            for w in workers
        ]
    except Exception as e:
        out["workers"] = f"ERROR: {e}"

    try:
        from rq.registry import FailedJobRegistry, FinishedJobRegistry
        from rq.job import Job
        from frappe.utils.background_jobs import get_queue
        recents = {}
        for name in ("short", "default", "long"):
            q = get_queue(name)
            fin = FinishedJobRegistry(queue=q)
            fail = FailedJobRegistry(queue=q)
            recents[name] = {"finished": [], "failed": []}
            for jid in fin.get_job_ids(0, 5):
                try:
                    j = Job.fetch(jid, connection=q.connection)
                    recents[name]["finished"].append({
                        "ended_at": str(j.ended_at), "func": j.func_name,
                    })
                except Exception:
                    pass
            for jid in fail.get_job_ids(0, 5):
                try:
                    j = Job.fetch(jid, connection=q.connection)
                    recents[name]["failed"].append({
                        "ended_at": str(j.ended_at), "func": j.func_name,
                        "exc_excerpt": (j.exc_info or "")[:200].replace("\n", " "),
                    })
                except Exception:
                    pass
        out["recent_jobs"] = recents
    except Exception as e:
        out["recent_jobs"] = f"ERROR: {e}"

    try:
        job = frappe.enqueue(
            "frappe.utils.background_jobs.test_job",
            queue="short", timeout=10, s=1,
        )
        deadline = time.time() + 10
        status = job.get_status()
        while time.time() < deadline and status not in ("finished", "failed"):
            time.sleep(0.5)
            status = job.get_status(refresh=True)
        out["smoke_test"] = {
            "final_status": status, "id": job.id,
            "exc_excerpt": (job.exc_info or "")[:300] if status == "failed" else None,
        }
    except Exception as e:
        out["smoke_test"] = {"error": str(e)}

    if verbose:
        print("== Redis ===========================================")
        print(f"  ping = {out['redis_ping']}")
        print("\n== Queues ==========================================")
        if isinstance(out["queues"], dict):
            for name, info in out["queues"].items():
                tag = "✓" if info["depth"] < 100 and info["failed"] == 0 else "⚠"
                print(f"  {tag} {name:8s}  depth={info['depth']:4d}  "
                      f"started={info['started']:3d}  "
                      f"failed={info['failed']:3d}  "
                      f"scheduled={info['scheduled']:3d}")
        else:
            print(f"  {out['queues']}")
        print("\n== Workers =========================================")
        if isinstance(out["workers"], list):
            print(f"  {len(out['workers'])} workers registered")
            for w in out["workers"]:
                print(f"    {w['name']}  state={w['state']}  queues={w['queues']}")
        else:
            print(f"  {out['workers']}")
        print("\n== Smoke test ======================================")
        if isinstance(out["smoke_test"], dict):
            st = out["smoke_test"].get("final_status")
            mark = "✓" if st == "finished" else "✗"
            print(f"  {mark} test_job final_status = {st}")
            if st == "failed":
                print(f"    {out['smoke_test'].get('exc_excerpt')}")
        else:
            print(f"  {out['smoke_test']}")
        print("\n== Recent jobs =====================================")
        if isinstance(out["recent_jobs"], dict):
            for name, info in out["recent_jobs"].items():
                print(f"  {name}: {len(info['finished'])} finished, "
                      f"{len(info['failed'])} failed (last 5)")
                for f in info["failed"]:
                    print(f"    FAILED {f['ended_at']}  {f['func']}: {f['exc_excerpt']}")

    return out


def queue_failures_for(func_name_pattern: str, limit: int = 20,
                       verbose: bool = True) -> List[Dict[str, Any]]:
    """Search RQ FailedJobRegistry for a function-name substring.
    Use BEFORE refactoring/moving a function (L-057)."""
    frappe.db.rollback()
    from rq.registry import FailedJobRegistry
    from rq.job import Job
    from frappe.utils.background_jobs import get_queue

    results = []
    for name in ("short", "default", "long"):
        q = get_queue(name)
        reg = FailedJobRegistry(queue=q)
        for jid in reg.get_job_ids(0, 200):
            try:
                j = Job.fetch(jid, connection=q.connection)
                fn = j.func_name or ""
                if func_name_pattern in fn:
                    results.append({
                        "queue": name,
                        "ended_at": str(j.ended_at),
                        "func": fn,
                        "exc_excerpt": (j.exc_info or "")[:400].replace("\n", " | "),
                    })
            except Exception:
                pass
        if len(results) >= limit:
            break

    if verbose:
        print(f"\nFailed jobs matching '{func_name_pattern}': {len(results)}")
        for r in results[:limit]:
            print(f"  [{r['queue']}] {r['ended_at']}  {r['func']}")
            print(f"    {r['exc_excerpt'][:300]}")
    return results[:limit]


def scheduled_crons(verbose: bool = True) -> List[Dict[str, Any]]:
    """List SP scheduled jobs. Use to verify `bench migrate` registered
    new scheduler_events entries (L-049)."""
    frappe.db.rollback()
    rows = frappe.db.sql(
        """
        SELECT name, method, cron_format, stopped, frequency
          FROM "tabScheduled Job Type"
         WHERE method LIKE 'tap_lms.%'
         ORDER BY method
        """,
        as_dict=True,
    )
    if verbose:
        print(f"\nSP-related Scheduled Job Type rows: {len(rows)}")
        for r in rows:
            mark = "✓" if not r["stopped"] else "✗ STOPPED"
            print(f"  {mark}  {r['method']}")
            print(f"      cron={r['cron_format'] or '-'}  "
                  f"freq={r['frequency'] or '-'}")
    return rows

def glific_fields(glific_id: str, keys: Optional[List[str]] = None,
                  verbose: bool = True) -> Dict[str, Any]:
    """Fetch SP-managed contact fields for a Glific contact."""
    if keys is None:
        keys = _SP_CONTACT_FIELDS_DEFAULT
    fields = _fetch_glific_contact_full(glific_id)
    out = {}
    for k in keys:
        v = fields.get(k)
        if isinstance(v, dict):
            out[k] = {"value": v.get("value"),
                      "inserted_at": v.get("inserted_at")}
        else:
            out[k] = v
    if verbose:
        print(f"\nGlific contact {glific_id} — {len(out)} fields:")
        for k in keys:
            entry = out.get(k)
            if isinstance(entry, dict):
                print(f"  {k:32s} = {entry['value']!r:15s}  "
                      f"(set {entry['inserted_at']})")
            else:
                marker = "✗ MISSING" if entry is None else ""
                print(f"  {k:32s} = {entry!r}  {marker}")
    return out

def _fetch_glific_contact_full(glific_id: str) -> Dict[str, Any]:
    if not glific_id:
        return {}
    try:
        from tap_lms.glific_integration import (
            get_glific_settings, get_glific_auth_headers,
        )
        settings = get_glific_settings()
        r = requests.post(
            f"{settings.api_url}/api",
            json={
                "query": "query c($id: ID!){contact(id:$id){contact{id fields}}}",
                "variables": {"id": str(glific_id)},
            },
            headers=get_glific_auth_headers(), timeout=15,
        ).json()
        raw = (r.get("data") or {}).get("contact", {}).get("contact", {}).get("fields")
        return json.loads(raw) if isinstance(raw, str) else (raw or {})
    except Exception:
        return {}


def _fetch_glific_contact(glific_id: str) -> Dict[str, Any]:
    raw_fields = _fetch_glific_contact_full(glific_id)
    out = {}
    for k, v in raw_fields.items():
        out[k] = v.get("value") if isinstance(v, dict) else v
    return out
